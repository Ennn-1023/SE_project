**Feature**：[../spec.md](../spec.md) | **Data model**：[../data-model.md](../data-model.md)

本功能沒有新增或修改任何 REST API。對外的介面只有瀏覽器路由與畫面行為，以下逐項列出可以驗證的合約。

## 2. 頁首與側邊選單

### 2.1 三條線按鈕（只出現在老師畫面）

- 位置：頁首最左側，在「課程搶答系統」之前。
- `<button type="button">`，大小至少 44×44px。
- `aria-label`：選單關閉時為「開啟選單」，打開時為「關閉選單」；`aria-expanded` 對應選單狀態。
- `aria-controls` 指向選單的 id。

### 2.2 選單

| 項目 | 合約 |
|------|------|
| 容器 | `role="dialog"`、`aria-modal="true"`、`aria-label="老師功能選單"`；從畫面左側滑出，寬度 `min(80vw, 18rem)`，高度佔滿視窗 |
| 遮罩 | 蓋住選單以外的區域，點擊後關閉選單 |
| 關閉按鈕 | 選單會蓋住頁首的三條線按鈕，所以在選單左上角、同一位置放一個「關閉選單」按鈕（× 圖示，至少 44×44px）。頁首按鈕不可浮在選單上方 |
| 項目 | 依序為「搶答活動」「題目管理」「學生管理」，每項都是連結，點擊區至少 44px 高 |
| 目前項目 | 加上 `aria-current="page"`，並以醒目樣式呈現（背景色加粗體，不只靠顏色） |
| 打開時 | 焦點移到第一個項目 |
| 焦點循環 | 選單打開時，Tab／Shift+Tab 只在選單內的關閉按鈕與項目之間循環：最後一項按 Tab 回到第一項，第一項按 Shift+Tab 到最後一項。焦點不會進入被遮罩蓋住的背景，與 `aria-modal="true"` 一致 |
| 關閉方式 | 點選任一項目（先導向再關閉）、按 Esc、點遮罩、按選單內的「關閉選單」按鈕、路由改變 |
| 關閉後 | 焦點回到三條線按鈕 |
| 不包含 | 開發工具、修改密碼、登出（後兩者仍在頁首右側） |
| 360px 寬 | 選單與遮罩都不造成水平捲動 |
| 減少動態效果 | 系統設定 `prefers-reduced-motion: reduce` 時，不播放滑入動畫 |

## 3. 學生管理畫面（`/teacher/students`）

- 由上而下依序為 `StudentCreatePanel`、`GroupManagePanel`，兩者以 refreshKey 互相連動，與舊的老師管理頁相同。
- 不再顯示前往「搶答活動」「題目管理」的按鈕，也不再顯示「模擬老師搶答操作（開發工具）」。

## 4. 標註區（`/teacher/questions` 的標註步驟）

由上而下：

1. **標題列**：「標註題目（N 題）」、「新增題目」、「清除所有標註重新開始」，與現行相同。
2. **題目總覽**（N ≥ 1 時顯示）：
   - 一排題號按鈕，可自動換行。
   - 按鈕文字為題號（例如「3」）。
   - 有錯的題目在前面加「⚠」，`aria-label` 為「第 3 題，有錯誤」；沒有錯的題目 `aria-label` 為「第 3 題」。
   - 目前這一題的按鈕加 `aria-current="true"`。
   - 點選按鈕即 `goTo`。
3. **逐題切換列**（N ≥ 1 時顯示）：
   - 「上一題」按鈕、位置提示「第 X 題／共 N 題」（`aria-live="polite"`）、「下一題」按鈕。
   - 在第一題時「上一題」停用（`disabled`）；在最後一題時「下一題」停用。
4. **步驟提示、取消、提示訊息、選取格資訊**：與現行相同。另外，當選取格屬於其他題、而且沒有進行中的步驟時，在選取格資訊旁顯示「前往第 N 題」按鈕。
5. **沒有對應題目的錯誤**：與現行相同。
6. **目前這一題的編輯卡片**：只有 1 張，內容與現行每題卡片相同：
   - 題號輸入、單題／題組切換、上移、下移、刪除；
   - 共同題幹；
   - 各小題的題目格與作答格；
   - 新增小題；
   - 該題的錯誤與提醒。
   N = 0 時，改為顯示「尚未標註任何題目，請按「新增題目」開始」。

### 格線角標

- 所有題目的角標都繼續顯示（題1、答1、幹3 等）。
- 目前這一題的角標另加外框（`ring-2`）並放到最上層，可以用 `data-current="true"` 驗證。

### 不變的部分

標註資料、本地驗證、草稿防抖自動儲存、確認匯入的阻擋規則、題數與小題數上限，全部與 003 相同。
