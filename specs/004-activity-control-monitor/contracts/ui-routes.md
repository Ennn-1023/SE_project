# 前端路由與畫面狀態（F5/F8）

## 路由

| 路徑 | 角色 | 頁面 | 說明 |
|------|------|------|------|
| `/teacher` | 老師 | `TeacherDashboard` | 新增「搶答活動」按鈕（FR-031） |
| `/teacher/activity` | 老師 | `ActivityControlPage` | 本功能主頁；學生進入時導回 `/student`（沿用 route guard） |
| `/student/buzzer`（002 既有搶答頁） | 學生 | `StudentPage` | 新增 `NO_ACTIVITY` 畫面、題組多作答框、結果依小題分列 |

`DevTeacherPanel`（002）只在 `ENABLE_DEV_TOOLS=true` 時顯示，新增「以 mock 題目開始活動」按鈕（FR-032）。

## `ActivityControlPage` 版面（mobile-first）

- 375–1023 px：單欄，由上而下為「狀態列 → 主要區（依階段）→ 題目清單（可收合）」。
- ≥ 1024 px：左欄題目清單（固定寬 320 px、獨立捲動），右欄主要區。
- 頂端狀態列常駐：階段標籤、進度「已完成 N／M 題」、連線狀態；作答中加上醒目提醒「作答中畫面含各組答案，請勿投影給學生」。

## 依階段的主要區

| 階段 | 元件 | 內容與操作 |
|------|------|-----------|
| `NONE` | `ActivityStartPanel` | 題目集來源與題數、參與組別（組數、各組人數）、「開始活動」（主要撞色）；缺題目集或組別時按鈕停用並顯示原因＋前往題目管理／組別管理的連結 |
| `WAITING` | `OpenQuestionForm` | 選取題目的完整內容（題組含共同題幹、各小題）、秒數欄位（預設 60，`inputMode="numeric"`，即時驗證 5～600 整數）、「開始搶答」（主要撞色）；已結束題目顯示「重新開放」（次要＋確認視窗） |
| `ANSWERING` | `MonitorBoard` | 倒數（`useServerCountdown`）、「已送出 N／M 組」、各組列（狀態、順位、+x.x 秒、送出者、答案依小題）、「目前最快」標籤、全部送出提示、「結束搶答」（破壞性樣式＋確認視窗）；歸零後顯示「時間到，結算中」 |
| `CLOSED` | `ResultBoard`＋`OpenQuestionForm` | 結果（依順位、搶答成功、未送出、結束原因）；下方以預選的下一題顯示開放表單；「回到等待畫面」（次要）；全部完成時改為提示「本場題目已全部完成，可結束活動」 |
| `ENDED` | `ActivitySummary` | 題數、已完成題數、每題搶答成功組別（可點開結果）、「開始新活動」（確認視窗） |

「結束活動」按鈕在 `WAITING`／`ANSWERING`／`CLOSED` 顯示於狀態列（破壞性樣式），確認視窗內容依未開放題數與是否作答中（spec US5-1、US5-2）。

## 題目清單 `ActivityQuestionList`

每列：題號、摘要、狀態徽章（未開放／作答中／已結束＋搶答成功組別或「無人送出」）。點選：
- `WAITING`／`CLOSED` 時未開放題目 → 設為開放表單的目標；
- 已結束題目 → 以對話框顯示 `ResultBoard`（唯讀，`GET …/questions/{id}/result`），對話框內提供「重新開放」。

## 共通狀態

| 狀態 | 呈現 |
|------|------|
| 載入中 | 主要區骨架、操作按鈕停用 |
| 請求進行中 | 該按鈕顯示處理中並停用（防連點，FR-014） |
| 斷線 | `ConnectionBanner`「連線中斷，正在重新連線，請稍後再操作」，所有操作停用（FR-025） |
| `notice` 有值 | 主要區上方提示框（例如重啟取消作答） |
| 錯誤 | `ErrorMessage` 顯示 `message`＋`hint`；409 後以回應中的最新狀態重新渲染 |

所有答案、組名以 React 文字節點輸出並套用 `white-space: pre-wrap`（FR-020）；長答案超過 6 行時可收合／展開。按鈕觸控區 ≥ 44 px，375 px 寬無水平捲動（FR-033、SC-009）。
