# UI 契約：寫回與匯出（F10＋F11）

沿用 004 的 `/teacher/activity`（`ActivityControlPage`），不新增路由。設計系統沿用 F0（米白底、撞色按鈕、觸控區 ≥ 44px、375～1440px 無水平捲動）。

## 入口

| 位置 | 元件 | 顯示條件 |
|------|------|----------|
| 活動頁頂部工具列 | 「寫回 Google 試算表」「匯出結果 CSV」 | 有最近一場活動時可按；`NONE` 時停用並顯示「尚無搶答活動結果可寫回或匯出」 |
| 活動結束摘要（`ActivitySummary`） | 同上兩個按鈕，醒目置於摘要下方 | 活動結束時 |

## `ExportCsvButton`

| 狀態 | 畫面 |
|------|------|
| 閒置 | 「匯出結果 CSV」（深藍撞色） |
| 下載中 | 按鈕停用＋「匯出中…」 |
| 成功 | 瀏覽器下載；按鈕恢復 |
| 失敗 | 按鈕下方顯示錯誤 message＋hint（`role="alert"`） |

## `WritebackPreviewDialog`

手機：全螢幕；桌機：置中、最大寬 960px、內容區垂直捲動。

| 步驟 | 內容 |
|------|------|
| 載入 | 「正在讀取學習單…」 |
| 錯誤 | message＋hint；`GOOGLE_NOT_CONNECTED`／`GOOGLE_AUTH_EXPIRED` 顯示「前往連結 Google 帳號」（導向 `/teacher/questions`）；`WRITEBACK_NOT_THIS_SHEET` 顯示學習單名稱與連結 |
| 預覽 | 1. 目標：試算表名稱／分頁名稱（連結）<br>2. 摘要：「N 格將寫入空白格、M 格將覆蓋既有內容、K 格已是相同內容、U 格無法定位」<br>3. 項目卡片（每題每小題一張）：題號＋小題、作答格位置（隱藏時加「此格目前被隱藏」）、成功組別、將寫入答案、目前內容、狀態徽章（將覆蓋＝珊瑚橘邊框）<br>4. `ANNOTATION_MISSING` 卡片：「找不到作答格標註（匯入時位置：G9，目前內容：…）」＋核取方塊「寫入匯入時的位置」（預設不勾）<br>5. `ANNOTATION_DUPLICATED` 卡片：「作答格標註重複，無法判斷位置，將略過；請重新匯入學習單修正標註」<br>6. 不寫入題目清單：「第 5 題：無組別送出，不寫入」「第 6 題：未開放，不寫入」「第 3 題：作答中，結束後才可寫回」<br>7. 覆蓋選項（有將覆蓋時才出現，radio 必選）：「全部覆蓋」／「略過已有內容的格子，只寫入空白格」<br>8. 按鈕：「取消」（一般）、「確認寫回」（珊瑚橘；必選項未選時停用） |
| 寫入中 | 確認按鈕停用＋「寫回中…」；對話框不可關閉 |
| 結果（`WritebackResultPanel`） | 「已寫回 N 格（M 題），其中 K 格覆蓋既有內容；略過 S 格（已有內容 X、找不到標註 Y、標註重複 Z）」＋「開啟試算表」（新分頁）＋「關閉」 |
| 已變動 | `WRITEBACK_STALE`：顯示變動題號＋「重新預覽」按鈕 |
| 已失效 | `WRITEBACK_PREVIEW_EXPIRED`：「預覽已失效」＋「重新預覽」 |

所有答案、組名、試算表內容以純文字呈現（React 文字節點，`white-space: pre-wrap`；不得使用 `dangerouslySetInnerHTML`，FR-027）。
