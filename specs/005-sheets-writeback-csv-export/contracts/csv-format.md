# CSV 格式契約：活動結果匯出（F11）

對應 spec FR-017～FR-022、[data-model.md §4](../data-model.md)、research R10、R11。

## 檔案

| 項目 | 規則 |
|------|------|
| 編碼 | UTF-8，開頭 BOM（`EF BB BF`） |
| 換行 | CRLF（`\r\n`），最後一列之後也有 CRLF |
| 分隔 | 逗號 `,` |
| 檔名 | `搶答結果_YYYYMMDD-HHmm.csv`（活動開始時間，伺服器本地時區）；`Content-Disposition` 同時提供 ASCII `filename="activity-results.csv"` 與 `filename*=UTF-8''…` |
| 個資 | 不含學生姓名、學號、帳號 |

## 標題列（固定順序）

```text
題號,小題,題目狀態,組別,搶答順位,是否搶答成功,送出時間（秒）,答案
```

## 欄位跳脫（依序套用）

1. **防公式注入**：值以 `=` 或 `@` 開頭 → 前置 `'`。以 `+`、`-`、Tab、CR 開頭 → 不變（spec Clarifications Q3；已知取捨見 spec Assumptions）。
2. **引號包覆**：值含 `,`、`"`、`\r`、`\n` → 以 `"` 包住，內部 `"` 改為 `""`。
3. 其他值原樣輸出（不額外加引號）。

適用於所有欄位（題號、小題、組名、答案）。

## 範例

活動：第 1 題單題（第 2 組最快、第 1 組次之、第 3 組未送出）；第 2 題題組 2 小題（第 1 組送出）；第 3 題作答中；第 4 題未開放。

```text
題號,小題,題目狀態,組別,搶答順位,是否搶答成功,送出時間（秒）,答案
1,,已結束,第 2 組,1,是,3.2,"光合作用,需要光"
1,,已結束,第 1 組,2,否,5.0,'=1+1
1,,已結束,第 3 組,未送出,否,,
2,（1）,已結束,第 1 組,1,是,12.4,"第一行
第二行"
2,（2）,已結束,第 1 組,1,是,12.4,-5 度
2,（1）,已結束,第 2 組,未送出,否,,
2,（2）,已結束,第 2 組,未送出,否,,
3,,作答中,,,,,
4,,未開放,,,,,
```

（實際檔案開頭有 BOM，換行為 CRLF。）
